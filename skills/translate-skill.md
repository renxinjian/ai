# Translate Skill

当用户调用 `/translate <目标语言>: <文本>` 时，将文本翻译成目标语言。

## 参数格式

```
/translate 日语: 你好世界
/translate English: 今天天气真好
/translate 法语: 机器学习是人工智能的一个分支
```

## 行为

1. 解析用户输入中的目标语言和待翻译文本
2. 将文本翻译成目标语言
3. 输出格式:
   ```
   原文: <原始文本>
   目标语言: <语言>
   译文: <翻译结果>
   ```

## 示例

用户: /translate 日语: 你好，今天过得怎么样？
助手:
原文: 你好，今天过得怎么样？
目标语言: 日语
译文: こんにちは、今日はどうでしたか？
