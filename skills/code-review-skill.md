# Code Review Skill

当用户调用 `/code-review` 时，对当前目录的代码进行审查。

## 行为

1. 用 `git diff` 查看所有未提交的变更
2. 从以下几个方面审查代码:
   - 潜在的 bug 或逻辑错误
   - 安全性问题 (XSS, SQL 注入, 命令注入等)
   - 代码风格和可读性
   - 性能问题
   - 是否有遗漏的边界情况处理
3. 按严重程度分类输出问题:
   - 🔴 严重: 必须修复
   - 🟡 建议: 值得改进
   - 🟢 小提示: 锦上添花

## 示例

用户: /code-review
助手: (先运行 git diff, 然后按严重程度列出发现的问题)
